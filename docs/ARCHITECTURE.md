# معماری — دستیار هوشمند آنی‌یاب v2

> یک صفحه. هدف: هر کسی در یک دقیقه بفهمد چه چیزی کجاست و چرا.

## نمای کلی

```
مرورگر (RTL / PWA)
   │  POST /api/chat  (SSE: token · tool · ui · memory · meta · error · [DONE])
   ▼
app/api/chat/route.ts          اعتبارسنجی zod → هویت دستگاه → بریف مشتری → استریم → پایداری
   │
   ├── lib/agent/router.ts        مسیرساز قطعی (IMEI، کد ملی، «فراموشم کن»، ثبت یافته)
   ├── lib/agent/orchestrator.ts  اجرای ابزار + حلقهٔ مدل (حداکثر ۴ گام)
   │      ├── lib/agent/tools.ts      ۱۳ ابزار zod؛ هیچ‌کدام throw نمی‌کند
   │      ├── lib/laya.ts             کلاینت API تصمیم Laya
   │      ├── lib/agent/laya-decisions.ts   پنج تصمیم (مسیریابی، سطح مدل، اولویت، تطبیق، تردید)
   │      └── lib/llm.ts              زنجیرهٔ مدل NVIDIA + سقف فیلدها
   ├── lib/agent/extract.ts       استخراج حافظه بعد از flush (waitUntil)
   └── lib/db/store.ts            تنها سطح دسترسی به داده
            ├── Supabase (service role)  ← وقتی env هست
            └── memory-store            ← وقتی نیست (دمو بی‌دردسر)
```

## چهار تصمیم که همه‌چیز را ساده می‌کند

1. **یک endpoint گفتگو.** `/api/chat` تنها دروازه است؛ منطق در `lib/agent/*` زندگی می‌کند و route فقط اعتبارسنجی و پایداری می‌کند.
2. **مسیرساز قطعی، مدل را دور نمی‌زند بلکه پشتیبان می‌گیرد.** اگر متن شامل IMEI معتبر یا کد ملی معتبر باشد، ابزار *قبل از* مدل اجرا می‌شود؛ نتیجه به‌صورت پیام `tool` به مدل داده می‌شود تا فقط روایت کند. نتیجه: دمو هرگز به شانس مدل وابسته نیست.
3. **وضعیت تیکت روی خواندن محاسبه می‌شود.** `lib/status.ts` از `created_at` مرحله را می‌سازد (۰ → ۱ → ۳ → ۸ → ۲۰ دقیقه). نه cron، نه worker، نه وب‌سوکت — تایم‌لاین خودش زنده است.
4. **داده ساختگی، رفتار واقعی.** همهٔ ردیف‌ها `is_demo = true`؛ کدها `AN-L-XXXXXX` / `AN-F-XXXXXX`؛ هیچ درگاه پرداختی وجود ندارد. CTA خرید به `NEXT_PUBLIC_SHOP_URL` می‌رود.

## مرزهای اعتماد

| لایه | قاعده |
|---|---|
| کد ملی | فقط SHA-256 با pepper (`lib/crypto.ts`)؛ رجیستری هیچ policy خواندنی برای کلاینت ندارد |
| IMEI / موبایل | در UI ماسک می‌شود (`lib/validators.ts`)؛ در لاگ‌ها redact |
| حافظه | وابسته به هویت دستگاه؛ `DELETE /api/memory` حق فراموش شدن را اجرا می‌کند |
| `/admin` | کوکی httpOnly + مقایسهٔ زمان‌ثابت + محدودیت ۵ تلاش/۱۰ دقیقه |
| نوشتن در DB | فقط service role از سمت سرور؛ RLS همهٔ نوشتن‌های کلاینت را می‌بندد |

## فایل‌های کلیدی

- `supabase/migrations/*` — طرح + RLS + Realtime.
