# فرض‌ها، محدودیت‌ها و چیزهایی که باید تأیید شود

> این سند صادقانه می‌گوید چه چیزی واقعی است، چه چیزی ساختگی است، و چه چیزی
> نیاز به تصمیم شما دارد. هر موردِ مشکوک با `CLAIM-REVIEW` علامت خورده است.

## ۱. آنچه واقعاً کار می‌کند

| قابلیت | وضعیت |
|---|---|
| گفتگوی استریم‌شده با ابزارهای واقعی (۱۳ ابزار) | ✔ کار می‌کند |
| اعتبارسنجی IMEI با چک‌سام **Luhn** | ✔ الگوریتم واقعی |
| اعتبارسنجی کد ملی با چک‌سام **ایران** | ✔ الگوریتم واقعی |
| محاسبهٔ هزینهٔ آگهی روزنامه (`lib/pricing.ts`) | ✔ قطعی و تست‌شده |
| تبدیل تاریخ شمسی (بدون وابستگی خارجی) | ✔ الگوریتم Borkowski |
| حافظهٔ مشتری + حق فراموش شدن | ✔ کار می‌کند |
| داشبورد ادمین + Realtime | ✔ با Supabase؛ بدون آن polling |
| PWA (manifest، SW، صفحهٔ آفلاین) | ✔ نصب‌پذیر |
| حالت scripted برای روز ارائه | ✔ بدون شبکه هم جواب می‌دهد |

## ۲. آنچه شبیه‌سازی شده (و باید شبیه‌سازی‌شده بماند)

- **استعلام دفاتر یافته‌ها**: جدول `registry_entries` ساختگی است (۶۲ ردیف نمونه). هیچ اتصالی به سامانهٔ واقعی ثبت احوال یا پلیس وجود ندارد.
- **تماس امن**: شمارهٔ رله `۰۲۱-۹۱۰۰xxxx` تولید می‌شود و ۱۵ دقیقه اعتبار دارد؛ هیچ مرکز تماسی پشت آن نیست. تماس واقعی برقرار نمی‌شود.
- **پست یافته**: کد `AN-P-XXXXXX` صادر می‌شود؛ اتصالی به شرکت پست ندارد.
- **آگهی روزنامه**: پیش‌فاکتور با تعرفهٔ ثابت محاسبه می‌شود؛ هیچ سفارش واقعی به روزنامه ارسال نمی‌شود.
- **OTP**: پیش‌فرض `12345` است و در کلاینت نمایش داده می‌شود. پیامکی ارسال نمی‌شود.
- **داشبورد ادمین**: داده‌اش واقعی است (همان DB)، اما «Customer-360» یک نمای دمویی است، نه ابزار عملیاتی.

## ۳. فرض‌های محصول

1. **برچسب = مشاوره، نه فروش.** هیچ سبد خریدی، هیچ پرداختی، هیچ آدرس‌گیری‌ای وجود ندارد. CTA نهایی کاربر را به `NEXT_PUBLIC_SHOP_URL` می‌فرستد و کلیک در جدول `events` ثبت می‌شود. اگر CEO انتظار «خرید درون‌چت» دارد، این یک تغییر دامنه است، نه یک تنظیم.
2. **قیمت‌ها ثابت‌اند**: آنی پارک ۳۴۹٬۰۰۰ و آنی پرو ۶۹۴٬۰۰۰ تومان، بدون اشتراک. اگر قیمت‌گذاری پویا لازم شد، `content/catalog.ts` تنها منبع است.
3. **هویت = دستگاه، بعد تلفن.** کاربر ناشناس با UUID محلی شروع می‌کند؛ تلفن فقط پس از OTP به همان رکورد می‌چسبد.
4. **حافظه به‌صورت پیش‌فرض روشن است.** `consent_memory` پیش‌فرض `true` است و در UI توضیح داده می‌شود. `CLAIM-REVIEW`: برای انتشار عمومی، رضایت صریح (opt-in) لازم است، نه opt-out.
5. **بدون Supabase هم باید کار کند.** این تصمیم آگاهانه است تا دموی محلی به شبکه وابسته نباشد؛ قیمتش این است که در حالت حافظه‌ای، داده با ری‌استارت پاک می‌شود.

## ۴. آنچه شما باید تأمین کنید

| مورد | چرا |
|---|---|
| `NVIDIA_API_KEY` | تنها کلید اجباری برای پاسخ‌های واقعی |
| `NEXT_PUBLIC_SUPABASE_URL` + `SUPABASE_SERVICE_ROLE_KEY` | دوام داده، Realtime ادمین |
| `PII_HASH_PEPPER` | سالت هش کد ملی؛ بعد از تولید داده قابل تغییر نیست |
| `ADMIN_PASSWORD` | بدون آن `/admin` کامل غیرفعال است (نمایش «تنظیم نشده») |
| `LAYA_API_ENDPOINT` + `LAYA_API_KEY` | فقط اگر Laya باید در زنجیره باشد |
| تصمیم دربارهٔ `NEXT_PUBLIC_DEMO_TOOLS` | `1` برای ارائه، `0` برای مشتری واقعی |
| دامنهٔ نهایی + دسترسی به پنل Vercel | دیپلوی و بررسی زندهٔ مدل |

## ۵. CLAIM-REVIEW — عبارت‌هایی که نباید بدون تأیید منتشر شوند

| عبارت در محصول | مشکل |
|---|---|
| «استعلام در دفاتر یافته‌ها» | دفاتر واقعی نیستند؛ باید «دفاتر همکار (نمایشی)» شود یا اتصال واقعی ساخته شود |
| «تماس امن بی‌نام» | مسیر رله فقط شبیه‌سازی است |
| «پست یافته» | بدون قرارداد با پست، تعهد لجستیکی ایجاد می‌کند |
| «۲۴ ساعته» برای پشتیبانی | عدد از بریف شماست؛ باید با واقعیت تیم هم‌خوان باشد |
| «پیش‌فاکتور صادر شد» | بدون تأیید روزنامه، فقط محاسبه است |
| «موردی با این کد ملی ثبت نشده» | می‌تواند به‌عنوان اظهارنظر رسمی دربارهٔ یک شهروند خوانده شود |

## ۶. محدودیت‌های فنی شناخته‌شده

- **بدون Supabase**: داده در حافظهٔ پروسه است؛ در Vercel هر instance حافظهٔ خودش را دارد. برای دموی تک‌کاربره کافی است، برای production نه.
- **Vercel serverless**: `waitUntil` برای استخراج حافظه استفاده می‌شود؛ در تابع‌های طولانی‌مدت ممکن است بریده شود (سقف `maxDuration=60`).
- **OCR/اسکن**: `BarcodeDetector` فقط در Chromium؛ در Safari به `jsQR` برمی‌گردد و اگر دوربین نبود، دکمهٔ «شبیه‌سازی اسکن» هست.
- **Lighthouse**: اعداد هدف (perf ≥ ۹۰، a11y ۱۰۰، BP ۱۰۰) روی موبایل با شبکهٔ throttle اندازه‌گیری می‌شوند؛ فونت Peyda محلی سرو می‌شود تا CLS و درخواست خارجی نداشته باشیم.
- **زبان**: همهٔ متن‌ها fa-IR و اعداد فارسی‌اند؛ تنها استثنا شماره‌های فنی (کد رهگیری، مدل) که با `dir="ltr"` نمایش داده می‌شوند.
